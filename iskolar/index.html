Iskolar: a privacy-first Chrome extension for student perks

A Chrome extension that shows students the discounts and education perks available on the website they are visiting, matched locally on the device with no tracking.

The project

Iskolar is built for students in the Philippines first, with global offers included. Click the extension icon on a website and it checks whether a student deal is known for that site, then shows the eligibility requirements, caveats, the last verification month, and a link to the official offer page.

It is a guide, not a guarantee. Offers change, so every card points back to the provider's own page for the current terms.

Privacy by design

Matching happens in the popup against an offer list that ships with the extension. It asks only for the activeTab permission, opens only HTTPS links, and does not collect browsing history, page content, accounts, or analytics. Theme and footer preferences stay on the device.

My role

I designed, built, and packaged Iskolar on my own. That covered domain matching against the bundled offers, region filtering for the Philippines and other countries, dark and light themes, a settings panel, and a browsable list of every student deal.

I also wrote a validation script that checks the offer data structure and HTTPS links, and prepared the Chrome Web Store listing, screenshots, privacy disclosures, and release package. The project is open source under the MIT License, with a README, a privacy policy, and a GitHub flow for reporting outdated offers.

What came of it

Version 1.0.1 has been submitted to the Chrome Web Store and is waiting for review. Offers are checked against official sources and reviewed by a person before each release, because automation may flag broken pages but should not publish student discounts.
