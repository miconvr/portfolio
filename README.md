This is the source code for my personal portfolio. It presents my projects, case studies, experience, and contact details.

The site is built with plain HTML, CSS, and JavaScript. It has no framework or build step and is deployed on Vercel.

## Features

- **In-place navigation:** About, Experience, and Contact load in the main panel without removing the sidebar
- **Project presentation:** featured project preview with case study, live site, and repository links
- **Responsive layout:** desktop sidebar layout that collapses cleanly on smaller screens
- **Motion:** page-panel transitions, scroll reveals, image movement, and link feedback with reduced-motion support
- **Accessible basics:** skip link, semantic landmarks, visible focus states, descriptive image text, and keyboard-friendly navigation
- **No build step:** static files that can be served with any simple local HTTP server

## Built with

- **Frontend:** HTML, CSS, and vanilla JavaScript
- **Layout:** CSS Grid, Flexbox, and responsive media queries
- **Fonts:** Manrope, Sora, and DM Mono
- **Hosting:** Vercel

## Deployment

Pushes to `main` trigger a new Vercel deployment.
